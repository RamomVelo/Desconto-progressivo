Sistema de Desconto Progressivo 🛒

Programa desenvolvido em Python para calcular descontos progressivos de acordo com o valor total de uma compra.

📋 Descrição

O programa solicita ao usuário o valor total da compra e verifica qual desconto deve ser aplicado conforme as regras definidas na atividade.

💰 Regras de desconto
Valor da compra	Desconto
Menor que R$ 200,00	5%
De R$ 200,00 até menor que R$ 300,00	10%
Maior ou igual a R$ 300,00	15%

Após identificar o percentual de desconto, o programa calcula:

Valor do desconto;
Percentual aplicado;
Valor final a ser pago.
